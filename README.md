# 看客 · 影视精简版

基于 Predidit/Kazumi 2.4.3（GPL-3.0）修改，本版版本号 2.4.9。iOS 包名保持 `local.kazumi.kanke.storm`，显示名称为“看客”。

## 2.4.9 手机解析回退

按最新要求，看客可在服务器授权后获取数据配置，由手机执行已审核的RC4采集/解析流程；风暴保留服务端解析。后台可选择直接手机解析或服务端优先、失败回退，并可关闭新的配置下发。App不内置生产源地址或密钥，不下载执行客户端代码，保留最新首页、播放器修复、历史及收藏。

该模式允许已授权用户提取下发配置，撤销授权不能收回已取得的信息。真实样本仍有上游返回空播放地址，尚未完成手机真机验收；见 verification/client-fallback-2.4.9.md。下面2.4.8为此前阶段实现记录。

## 2.4.8 服务端授权与动态来源

片源配置、采集、解密与播放解析已迁到独立服务，App只请求 `https://spht.longxuan.me` 的授权与资源API。首次启动提交本机密钥签名的设备申请，管理员批准后自动完成会话验证。来源列表从服务器加载，原首页、搜索、分类、详情、线路、收藏及历史模型保留。在线本地规则和WebView解析回退已停用；新解析不包含第三方接口配置、密钥或账号。

后台、接口、安全边界和部署说明在工作区独立的 `resource-server/README.md`；本仓库不含生产数据库、服务端密钥或初始管理员凭证。原看客播放涉及第三方账号时，必须先在服务器配置合法凭证；上游数据库错误不能由客户端绕过。iOS平台密钥代码尚待macOS编译/真机验收。

Android release启用R8和Dart混淆，使用原包名和保留的外部签名密钥。维护来源和解析规则不再需要更新App。已发出的公开直链/已下载视频无法靠授权撤销追回，平台完整性证明仍需正式分发平台配置。

## 2.4.7 首页排版

- 首页采用已选定的分类分区布局：电影、短剧、电视剧等分区，手机每行三张完整海报并提示下一张，支持横滑和“查看全部”。分类及影片均来自当前片源。
- 顶部来源切换、搜索和分类入口更紧凑；海报统一 2:3，集数/更新提示置于海报底部。分类及搜索结果使用手机三列、平板自适应网格。
- 保留原有收藏、历史、下载及主题设置，包含 2.4.6 的竖屏全屏和实际分辨率功能。
- 分区请求最多并发三项，独立失败可重试；切换来源时丢弃旧请求结果。分类服务失败时回退到普通片库，搜索仍可使用。
- 新增 13 项交互与布局回归，完整本机测试 263 项通过，静态检查无错误或警告。原生渲染已与选定方案对照；iPhone 实机验收仍待安装验证。

## 2.4.6 修复与功能

- 全屏根据视频显示方向选择横竖屏，9:16 短剧保持竖屏；支持视频旋转信息、提前进入全屏及全屏中换集。
- 播放器控件和视频详情显示实际解码分辨率，例如 `1080 × 1920`。读取前显示“读取中”，换集或换线路后重新读取，不使用片源清晰度标签或屏幕尺寸。
- 新增五项回归，完整本机测试 250 项通过；iPhone 实际旋转和播放效果仍需安装验证。

## 2.4.5 修复

修复详情页和播放器唤出控件时，收藏组件错误读取页面级状态而形成灰色错误区域的问题。收藏状态继续使用应用级单例，新增横竖屏显示及收藏操作回归。

## 使用

- 底部仅保留“影视、收藏、我的”。影视内选择服务器启用的来源，浏览、搜索、查看详情、播放和选集切线。
- 详情或播放器内一键收藏，再从收藏页返回原来源。旧收藏缺少来源信息时按片名重新搜索，不删除旧数据。
- “我的”提供历史、下载、来源检测、播放设置、外观和存储管理。
- 播放失败页面的刷新按钮会重新解析当前剧集。也可返回详情重新获取剧集列表，或切线路、切来源。
- 来源页检测片库接口是否可连接；它不代表每部影片、每条线路都可用。来源及解析规则由管理员在服务端维护，不向App下发执行代码。

## 精简范围

移除动漫推荐、放送时间表、追番状态菜单、Bangumi 账户/同步界面、角色与评论界面、以图搜番、原版规则商店和上游更新入口。播放器移除弹幕发送、弹幕设置、分集评论和一起看入口。来源页显示服务器启用的影视来源。

启动时关闭旧版可能留下的 Bangumi/WebDAV 自动同步、上游自动更新和弹幕缓存开关，并将已移除的默认启动页迁移到影视。保留收藏、历史、下载文件和播放器共用存储格式，保留原有来源记录以支持历史恢复。共用播放/存储底层仍使用部分上游模型名称。

## 构建

使用 Flutter 3.47.9 / Dart 3.13.7。iOS 在 macOS/Xcode 构建，依赖 CMake/Ninja。

```sh
python3 tool/fetch_assets.py
flutter pub get
dart analyze lib test tool
flutter test --no-pub
flutter build ios --release --no-codesign
```

工作流 `.github/workflows/build-ios-trial.yml` 生成未签名 IPA，不自动发布 Release。安装到 iPhone 仍需签名。

Windows 本机回归使用 `.qa-kazumi-native` 的上游官方 DLL 和专用 hook；`pubspec_overrides.yaml` 属于本机 QA，不交付、不用于 iOS 云构建。测试结论不等同于 iPhone 真机验收。
